# Сайт кофейни «Зерно»

Одностраничный сайт-визитка: обычные файлы HTML, CSS и немного JavaScript. Никаких сборщиков, баз данных и админок. Всё, что нужно поменять, лежит в понятных местах.

## Редактор: как менять цены, тексты и фото без кода

Откройте файл **`redaktor.html`** двойным кликом (лучше в Chrome или Edge на компьютере). Это обычная страница, она работает на вашем компьютере и ничего никуда не отправляет.

1. Нажмите «Выбрать папку сайта» и выберите папку `zerno` (один раз; браузер запомнит, при следующем открытии нужно будет лишь подтвердить доступ).
2. Меняйте:
   - **Контакты:** адрес, часы, телефон, ссылки, карта, удобства;
   - **Праздник:** баннер дня рождения (можно выключить или поменять дату, после которой он исчезает);
   - **Тексты:** слоган и абзацы «О нас»;
   - **Меню и цены:** переименовать, поправить цену, добавить, убрать, переставить позиции и категории;
   - **Фото:** загрузить, заменить, подписать, переставить. Редактор сам уменьшает снимки до лёгкого размера.
3. Нажмите «Сохранить на сайт». Файлы обновятся сами. Откройте `index.html` и обновите страницу (F5).
4. Если настроена публикация в интернет (файл `ПУБЛИКАЦИЯ.md`), то вместо шагов 1 и 3 просто нажмите «Сохранить и опубликовать»: через 1–2 минуты правки на сайте. Ничего загружать не нужно.

Что важно знать:
- Редактор **не меняет сайт в интернете сам**. Он правит файлы в вашей папке, а на хостинг их нужно загрузить. Это нарочно: никто посторонний не сможет ничего поменять на сайте.
- Перед каждым сохранением прежний `data.js` копируется в `data.backup.js`: если что-то пошло не так, можно вернуть.
- Желтые поля — места, где ещё остались `[[заглушки]]`. Кнопка «Показать незаполненное» внизу ведёт по ним по очереди.
- Если вписали адрес сайта в поле «Адрес сайта», редактор сам обновит заголовок, описание, превью для соцсетей, данные для поисковиков, `sitemap.xml` и `robots.txt`.
- В Firefox, Safari и на телефоне запись в папку недоступна: кнопка превратится в «Скачать архив». Распакуйте его в папку сайта с заменой файлов.
- Файл `redaktor.html` закрыт от поисковиков. Выкладывать его в интернет не нужно: можно не загружать вместе с сайтом `redaktor.html`, `js/redaktor.js` и `data.backup.js`. Если загрузите, ничего страшного: он только покажет формы, а сохранить в интернете ничего не сможет.

## Что где лежит

| Файл или папка | Что это |
|---|---|
| `index.html` | Вёрстка страницы (тексты берутся из `data.js`) |
| `redaktor.html` | **Редактор: цены, меню, тексты, контакты, фото** |
| `data.js` | Все тексты, контакты, меню и список фото (его переписывает редактор) |
| `css/style.css` | Цвета, шрифты, размеры (в самом начале файла) |
| `js/main.js` | Мелкие скрипты (меню на телефоне, появление блоков, карта) |
| `assets/` | Логотип, значки, шрифты, фото |
| `photos-original/` | Сюда класть свои фото до сжатия |
| `tools/` | Команды для сжатия фото и проверки сайта |
| `ПУБЛИКАЦИЯ.md` | Как получить ссылку на сайт и включить публикацию из редактора |
| `Открыть сайт.bat`, `Открыть редактор.bat` | Ярлыки: открыть сайт или редактор двойным кликом |
| `TODO.md` | Полный список того, что нужно заполнить |
| `robots.txt`, `sitemap.xml`, `site.webmanifest` | Служебные файлы для поисковиков |

## Как посмотреть сайт у себя

**Самый простой способ:** дважды щёлкните по `index.html`. Откроется в браузере, меню и фото работают и так.

**Через локальный сервер** (так сайт ведёт себя так же, как в интернете):

```bash
python3 -m http.server 8000
```

Потом откройте в браузере `http://localhost:8000`. (На Windows вместо `python3` может понадобиться `python`.)

## Как поменять текст вручную (без редактора)

Все тексты лежат в `data.js`, в разделе `texts`, `site` и `birthday`. Откройте файл в текстовом редакторе, меняйте слова внутри кавычек, сохраните и обновите страницу.

Заголовок вкладки, описание и данные для поисковиков (блок между `SEO:НАЧАЛО` и `SEO:КОНЕЦ` в `index.html`) вручную лучше не править: их пересоздаёт редактор.

Места, которые нужно заполнить, помечены `[[ТАК]]`. Полный список в `TODO.md`.

## Как поменять меню вручную (без редактора)

Откройте `data.js`. Меню выглядит так:

```js
{ "name": "Капучино", "price": 230, "note": "" },
```

- Поменять цену: исправьте число (без знака ₽, он добавится сам).
- Поменять название: исправьте текст в кавычках.
- Добавить позицию: скопируйте любую строку целиком и поменяйте в ней слова.
- Убрать позицию: удалите всю строку от `{` до `},`.
- Добавить описание: впишите его в `note: "..."`.
- Не удаляйте кавычки и запятые в конце строк: тогда сайт не сломается.

Пока в категории `"example": true`, на сайте рядом с ней стоит пометка «пример». Когда внесёте настоящие данные, поменяйте на `false`.

Если после правки меню пропало, значит, где-то потерялась кавычка или запятая. Вернитесь к последней рабочей версии или сравните строку с соседними.

## Как заменить фото (удобнее в редакторе, раздел «Фото»)

Ниже способ через команду: он нужен, если фото много и нужны ещё более лёгкие файлы AVIF. Скрипт сам уменьшит снимки и сделает три размера.

1. Один раз установите [Node.js](https://nodejs.org) (версия LTS) и в папке `tools` выполните:
   ```bash
   npm install
   ```
2. Положите JPG-фото в папку `photos-original/`. Названия лучше латиницей (`stol-u-okna.jpg`). Если названия русские, скрипт назовёт их `foto-1`, `foto-2` и так далее.
3. Запустите:
   ```bash
   npm run photos
   ```
   Скрипт создаст в `assets/photos/` по три размера каждого фото (480, 800 и 1200 пикселей) в форматах WebP и AVIF. Они в разы легче исходных. Заодно он убирает из фото служебные данные (например, геопозицию съёмки) и выравнивает повёрнутые снимки.
4. В конце скрипт напечатает строки вида:
   ```js
   { "file": "stol", "alt": "ОПИШИТЕ, ЧТО НА ФОТО", "caption": "", "w": 1200, "h": 1600, "size": "tall", "avif": true },
   ```
   Скопируйте их в файл `data.js` в список `gallery` вместо строк-заглушек. В `alt` напишите, что на фото («Столик у окна, на нём чашка капучино»), это важно для слабовидящих и для поиска. В `caption` можно написать подпись, которая будет на фото.
5. Сохраните и обновите страницу.

Подходит от 6 до 10 фото. Лишние заглушки удаляйте. Все фото на сайте автоматически получают одинаковую мягкую цветокоррекцию, поэтому снимки с разным светом смотрятся ровнее.

Совет: снимайте у окна днём, без вспышки, и протрите объектив.

## Как выбрать логотип

Сейчас на сайте и в значке вкладки (favicon) используется новый вариант: зерно и слово «Зерно». Лежит в `assets/logo-proposal.svg`.

Чтобы использовать логотип, который нарисовала подруга:

1. Сохраните его как `assets/logo.svg` (если файл PNG, то `assets/logo.png`, и в `index.html` в строке `<img src="assets/logo.svg" …>` поменяйте `.svg` на `.png`).
2. Логотип должен быть примерно вдвое шире, чем высота, и на светлом фоне. Если квадратный, поменяйте в строке `<img …>` значения `width` и `height` на одинаковые (например, 44 и 44).

Чтобы вернуть новый вариант, скопируйте `logo-proposal.svg` поверх `logo.svg`.

Значок вкладки (`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`) сделан из нового знака. Если выберете логотип подруги, значки нужно будет нарисовать заново по её рисунку.

## Как убрать баннер дня рождения

Баннер **пропадёт сам с 8 ноября 2026**, ничего делать не нужно.

Чтобы убрать его раньше или навсегда: в `index.html` найдите блок между двумя комментариями

```html
<!-- ===== БАННЕР ДНЯ РОЖДЕНИЯ: НАЧАЛО ===== -->
…
<!-- ===== БАННЕР ДНЯ РОЖДЕНИЯ: КОНЕЦ ===== -->
```

и удалите всё от первого комментария до второго включительно. Больше ничего менять не надо.

Чтобы использовать баннер для другого события, поменяйте дату в `data-hide-after="2026-11-08"` (день, начиная с которого баннер скрывается) и тексты внутри.

## Как выложить сайт в интернет (бесплатно)

**Рекомендуемый способ: GitHub Pages + редактор. Он описан по шагам в файле `ПУБЛИКАЦИЯ.md`**: после настройки директор сам публикует правки одной кнопкой, без Git. Ниже короткие варианты «просто выложить папку».

Любой из трёх вариантов подходит. Самый простой для новичка: **Cloudflare Pages** или **Netlify**, потому что можно просто перетащить папку.

### Netlify (перетащить папку)
1. Зарегистрируйтесь на [netlify.com](https://www.netlify.com).
2. В разделе «Sites» найдите область «Drag and drop your site folder» и перетащите туда папку сайта (саму папку `zerno` со всем содержимым, но без папок `tools/node_modules` и `photos-original`, чтобы не выкладывать лишнее).
3. Через минуту сайт появится по адресу вида `что-то.netlify.app`. Имя можно поменять в настройках сайта.

### GitHub Pages
1. Зарегистрируйтесь на [github.com](https://github.com) и создайте репозиторий (публичный).
2. Загрузите в него файлы сайта (кнопка «Add file → Upload files»).
3. В «Settings → Pages» выберите ветку `main` и папку `/ (root)`, нажмите Save.
4. Через пару минут сайт будет по адресу `ваше-имя.github.io/название-репозитория`.

### Cloudflare Pages
1. Зарегистрируйтесь на [pages.cloudflare.com](https://pages.cloudflare.com).
2. «Create a project» → «Direct Upload», загрузите папку сайта.
3. Адрес будет вида `имя.pages.dev`.

**Как обновлять:** поменяли файлы на компьютере, загрузили заново (в Netlify и Cloudflare это та же перетаскиваемая папка, в GitHub через «Upload files»). Через минуту изменения на сайте.

Перед выкладыванием: в папке `tools` выполните `npm run check`. Команда покажет, сколько заглушек `[[...]]` осталось, и найдёт битые ссылки.

## Как подключить свой домен

1. Купите домен у любого регистратора (reg.ru, nic.ru, Timeweb, Cloudflare и др.). `.ru` стоит около сотни-двух рублей за первый год.
2. В настройках сайта на выбранном сервисе (Netlify: «Domain management», GitHub Pages: «Settings → Pages → Custom domain», Cloudflare: «Custom domains») добавьте домен. Сервис покажет, какие записи нужно создать у регистратора (обычно `CNAME` или `A`).
3. Зайдите в панель регистратора, раздел «DNS» или «Управление DNS», и создайте эти записи так, как написал сервис.
4. Подождите от нескольких минут до суток. HTTPS (замочек) включится сам.
5. Когда домен заработает, замените `[[ДОМЕН]]` во всех файлах на настоящий адрес (см. `TODO.md`, раздел 4).

## Что ещё нужно сделать, чтобы кофейню находили (вне сайта)

Сайт сам по себе поиск не решает. Большинство людей ищут кофейню «рядом» на картах, и карточка там важнее сайта.

1. **Яндекс.Карты и Яндекс.Бизнес.** Создайте карточку организации на [yandex.ru/sprav](https://yandex.ru/sprav): адрес, часы, телефон, фото, ссылка на сайт, меню. Подтвердите, что это ваша кофейня.
2. **2ГИС.** Так же на [2gis.ru/business](https://2gis.ru/business) (карточка могла уже быть: тогда нужно получить на неё права).
3. **Google Business Profile.** [business.google.com](https://business.google.com): тот же набор данных. Нужен для Google Карт и поиска Google.
4. **Адрес, название, телефон и часы работы должны совпадать везде до запятой**: на сайте, в блоке для поисковиков в `index.html`, в картах, в соцсетях. Если где-то «ул. Ленина, 5», а где-то «Ленина 5», поиск считает это разными местами и ранжирует хуже.
5. **Просите отзывы.** Гости, которым понравилось, могут оставить отзыв на картах. Это самый сильный сигнал для местного поиска.
6. **Ссылка на сайт** в шапке профиля в соцсетях (VK, Telegram) и в карточках на картах.
7. **Яндекс.Вебмастер и Google Search Console.** После подключения домена добавьте сайт и отправьте `sitemap.xml`, так страница проиндексируется быстрее.
8. **Яндекс.Метрика (по желанию).** Счётчик уже предусмотрен закомментированным блоком в `<head>` файла `index.html`. Если подключите, на сайте нужно короткое уведомление про cookie.

## Как устроен сайт (для того, кто будет дорабатывать)

- Шрифты Lora и Nunito лежат в `assets/fonts/` (лицензии рядом), с внешних сервисов ничего не грузится.
- Фото в `data.js` выводятся через `<picture>` с AVIF и WebP, `loading="lazy"`, `width` и `height`, `object-fit: cover`.
- Карта (iframe) подгружается только по нажатию на кнопку, чтобы не замедлять страницу и не отправлять данные посетителей на сторонний сервис раньше времени.
- Анимации появления отключаются, если в системе включено «уменьшить движение» (`prefers-reduced-motion`). Если в браузере отключён JavaScript, остаются видны тексты, навигация и контакты, а меню кофейни и галерея не показываются (вместо меню появится подсказка).
- Незаполненные ссылки `[[...]]` на странице подсвечены и не уводят на несуществующие адреса.
- Скрипты в `tools/`: `npm run photos` (сжатие фото), `npm run check` (поиск заглушек и битых ссылок), `npm run brand` (перерисовывает логотип, значки и картинку для превью; нужен только если хотите изменить знак).
