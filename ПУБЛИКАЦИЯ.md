# Как выложить сайт в интернет, чтобы директор правил его сам

Цель: у сайта есть ссылка, а директор меняет цены и тексты на странице `redaktor.html`, нажимает «Сохранить и опубликовать», и через 1–2 минуты правки видны всем. Ни Git, ни загрузка файлов ему не нужны.

Настраивается **один раз**, около 20–30 минут. Нужны: компьютер, почта, любой браузер.

## Что нужно понимать (коротко)
- **GitHub** — бесплатное хранилище файлов сайта в интернете. Из него же сайт и показывается людям (**GitHub Pages**).
- **Репозиторий** — папка сайта на GitHub.
- **Ключ доступа** — длинный пароль, который разрешает менять файлы только этого сайта. Его один раз вставляют в редактор на устройстве директора.
- Бесплатный GitHub Pages работает только с **публичным** репозиторием: файлы сайта видны всем. Секретов в сайте нет (его всё равно видят все посетители).

---

## Шаг 1. Аккаунт GitHub
1. Откройте [github.com](https://github.com) → Sign up. Укажите почту, придумайте логин и пароль.
2. Логин станет частью адреса сайта: `логин.github.io/название-сайта`. Выбирайте короткий и понятный, например `zerno-cafe`.
3. Если сайт будет принадлежать кофейне, лучше регистрировать на почту кофейни или директора. Позже репозиторий можно передать (Settings → Transfer ownership).

## Шаг 2. Загрузить сайт на GitHub
Вариант А (проще, если у помощника настроен вход через `gh`):
помощник создаёт репозиторий и заливает сайт одной командой.

Вариант Б (без командной строки): программа **GitHub Desktop**
1. Скачайте [desktop.github.com](https://desktop.github.com), войдите в свой аккаунт.
2. File → Add local repository → выберите папку `zerno` (в ней уже есть Git-история).
3. Нажмите **Publish repository**. Название: `zerno-site`. **Снимите галочку «Keep this code private»** (для бесплатных страниц репозиторий должен быть публичным).

## Шаг 3. Включить сайт (GitHub Pages)
1. Откройте репозиторий на github.com → **Settings** → слева **Pages**.
2. В разделе Build and deployment: Source = **Deploy from a branch**; Branch = **main**, папка **/ (root)** → Save.
3. Подождите 1–2 минуты. На этой же странице появится адрес: `https://логин.github.io/zerno-site/`. Откройте его: это и есть сайт.

## Шаг 4. Создать ключ доступа для редактора
1. github.com → ваша аватарка справа вверху → **Settings** → в самом низу слева **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Token name: `zerno-editor`. Expiration: **1 year** (максимум; поставьте себе напоминание обновить за неделю до конца).
3. Repository access: **Only select repositories** → выберите `zerno-site`.
4. Permissions → **Repository permissions** → найдите **Contents** → переключите на **Read and write**. Больше ничего не включайте.
5. **Generate token**. Появится строка вида `github_pat_…`. **Скопируйте её сразу** (потом её уже не показать).

## Шаг 5. Подключить ключ к редактору
1. Откройте `https://логин.github.io/zerno-site/redaktor.html` (на компьютере директора и/или на её телефоне).
2. Внизу, в разделе **Публикация**, впишите: имя на GitHub, название репозитория (`zerno-site`), ветку `main` и вставьте ключ.
   Если страница открыта на `…github.io`, имя и репозиторий подставятся сами.
3. Нажмите **Проверить подключение**. Должно появиться «Всё подключено».
4. Добавьте страницу в закладки: теперь внизу кнопка называется **«Сохранить и опубликовать»**.

Ключ хранится только в браузере этого устройства. На новом устройстве его нужно вставить снова.

## Шаг 6. Ссылка для директора (чтобы она ничего не искала и не вводила)
1. В редакторе, раздел «Публикация», нажмите **«Скопировать ссылку для директора»**.
2. Отправьте эту ссылку директору **лично** (в личные сообщения, не в общий чат).
3. Директор открывает ссылку на своём телефоне или компьютере. Редактор сам запоминает доступ и убирает ключ из адресной строки. Больше ничего вводить не нужно.
4. Пусть добавит страницу в закладки или на главный экран телефона. Дальше она открывает закладку, правит и нажимает «Сохранить и опубликовать».

Важно:
- Ссылка работает как пароль: у кого она есть, тот может менять сайт. Отправляйте только директору и не пересылайте дальше.
- Если ссылка попала не туда или телефон потерян: GitHub → Settings → Developer settings → Fine-grained tokens → удалите ключ `zerno-editor`, создайте новый и сделайте новую ссылку (шаги 4–6).
- Перед истечением срока ключа (через год) повторите шаги 4–6.
- Доступ запоминается на каждом устройстве отдельно, и сохраняется, пока директор не очистит данные браузера.

## Как работает директор (каждый день)
1. Открыть закладку «Редактор Зерно».
2. Поправить цену, текст или фото.
3. Нажать **«Сохранить и опубликовать»**.
4. Через 1–2 минуты открыть сайт и обновить страницу.

## Важно: править нужно только онлайн-редактор
- Редактор нужно открывать **по ссылке в интернете** (`https://facxzv.github.io/zerno-site/redaktor.html`) или через ссылку-приглашение, а не из папки на компьютере.
- Копия редактора из папки (двойной клик по файлу) ничего не публикует: ключа в ней нет, и она предлагает только скачать архив. Ярлыки `Открыть сайт.bat` и `Открыть редактор.bat` теперь открывают онлайн-версию.
- Папка на компьютере со временем устаревает: правки, сделанные в интернете, в неё сами не попадают. Чтобы обновить её, откройте терминал в папке сайта и выполните `git pull`. Для обычной работы директору папка не нужна.

## В адресе слово «github»: как сделать красивый адрес
Адрес вида `facxzv.github.io/zerno-site` бесплатный. Чтобы он выглядел как `zerno-cafe.ru`, нужен свой домен:
1. Купите домен у регистратора (reg.ru, nic.ru, Timeweb…): около 200 ₽ в год за `.ru`. Купить может только владелец, мне это сделать нельзя.
2. Когда домен куплен, я включу его на стороне GitHub (поле Custom domain и HTTPS), а вы у регистратора добавите DNS-записи, которые покажет GitHub. Подождать до суток.
3. После этого сайт и редактор будут открываться по `https://zerno-cafe.ru/` и `https://zerno-cafe.ru/redaktor.html`. Ссылку-приглашение нужно будет сделать заново.

Бесплатные адреса без слова «github» (например `zerno.netlify.app` или `zerno.pages.dev`) тоже есть, но это те же поддомены чужих сервисов; нормальный адрес даёт только свой домен.

## Адрес сайта на латинице: `zerno-cafe.ru`
1. Купите домен у регистратора (reg.ru, nic.ru, Timeweb…), около 200 ₽ в год за `.ru`.
2. Репозиторий → Settings → Pages → **Custom domain**: впишите домен → Save.
3. У регистратора в разделе DNS создайте записи, которые покажет GitHub (обычно четыре записи `A` на адреса GitHub Pages и `CNAME` для `www`). Сверьтесь с [документацией GitHub](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site).
4. Подождите до суток, включите «Enforce HTTPS».
5. В редакторе, раздел «Контакты» → поле «Адрес сайта», впишите новый домен (без `https://`): редактор сам обновит данные для поисковиков.

## Если что-то не работает
| Что видите | Что делать |
|---|---|
| «Ключ доступа не подошёл или истёк» | Создайте новый ключ (шаг 4) и вставьте в «Публикацию». |
| «Нет доступа к репозиторию» | Проверьте имя и название репозитория. У ключа должно быть **Contents: Read and write** именно для этого репозитория. |
| «Пока вы правили, сайт успел измениться» | Обновите страницу редактора (F5) и повторите: кто-то (или вы с другого устройства) уже опубликовал правки. |
| Сайт не обновился | Подождите 2–3 минуты и обновите страницу (Ctrl+F5). В репозитории вкладка **Actions** показывает ход публикации. |
| Редактор не публикует, но скачать архив можно | Кнопка «Скачать архив» всегда работает. Распакуйте архив в папку сайта. |

## Безопасность
- Ключ даёт право менять **только этот сайт**, аккаунт и пароль от него недоступны.
- Если телефон или компьютер потеряны: GitHub → Settings → Developer settings → Fine-grained tokens → **Delete**, и создайте новый.
- Никому не присылайте ключ в мессенджерах и не вставляйте в чаты. Вставляйте только в поле редактора.
- Редактор `redaktor.html` лежит на сайте открытым, но без ключа он сохранять не умеет. Если не хотите, чтобы он вообще был виден, не загружайте `redaktor.html` и `js/redaktor.js` (тогда правки делайте у себя локально).

## Быстрый вариант без GitHub (на субботу)
Если нужна просто ссылка быстро: откройте [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите туда папку `zerno`. Через минуту будет адрес вида `что-то.netlify.app`. Минус: при каждой правке папку надо перетаскивать заново, а редактор сохранять на такой сайт не сможет. Потом можно перейти на GitHub по шагам выше.
